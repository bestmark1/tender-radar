# MRD — Тендер-радар (Market Requirements Document)

> Роль: Market PM (Full mode). Рыночная рамка: ICP, JTBD, альтернативы, позиционирование, рамка успеха и рыночные ограничения.

## 1. Целевой пользователь / ICP

**Первичный ICP (MVP):** микро- и малые компании-поставщики (ИП и ООО, 1–20 чел.), для которых госзаказ — значимый или основной канал выручки, работающие в **узкой товарной/услуговой вертикали** (например: поставка/обслуживание оргтехники, клининг, продукты питания для бюджетных учреждений, строительные материалы, медрасходники). Один-два человека отвечают за поиск тендеров.

**Почему именно они:**
- Дорогие агрегаторы (15–50 т.р./мес) для них чувствительны по цене.
- Узкая вертикаль = небольшой набор ОКПД2 и регионов → попадает в технические ограничения MVP (фильтрация на нашей стороне, узкий скоуп).
- Боль острая и денежная: пропущенный тендер = упущенный контракт.

**Вторичный ICP (Фаза 2+):** тендерные отделы среднего бизнеса (нужны команды, роли, CRM-интеграция), тендерные агентства/сопровождение (white-label).

**Анти-ICP:** крупные корпорации с собственными отделами и подписками на Контур/СБИС; компании вне госзаказа.

## 3. Альтернативы и конкурентный контекст

| Альтернатива | Цена | Плюсы | Минусы (наша возможность) |
|---|---|---|---|
| **Ручной мониторинг zakupki.gov.ru** | 0 ₽ + время | Бесплатно, официально | Часы рутины, пропуски, нет напоминаний |
| **Контур.Закупки / СБИС / Тендерплан** | 15–50 т.р./мес | Полнота, аналитика, поддержка | Дорого для микробизнеса, негибкие правила, чужой интерфейс, не self-hosted |
| **Сторонние JSON-API (DaMIA, GosPlan, Мультитендер)** | платно по запросам | Снимают возню с SOAP | Это «сырьё», а не продукт; нет дашборда/правил/уведомлений |
| **Самописный парсер** | время | Полный контроль | После закрытия FTP — высокий порог (SOAP+токен), поддержка XSD |
| **Тендер-радар (мы)** | дёшево / self-hosted | Гибкие правила под клиента, дешевле, свои данные, e-mail/VK, open-стек | Узкий MVP-скоуп, без аналитики/подачи заявок на старте |

**Вывод по конкуренции:** мы не бьёмся с Контуром по полноте. Мы занимаем нишу «дёшево + гибко + self-hosted + под узкую вертикаль», недообслуженную дорогими комбайнами. Для портфолио конкурентная плотность несущественна — важна демонстрация навыка.

## 4. Гипотеза позиционирования

> **Для** микро- и малых поставщиков в узкой вертикали госзаказа,
> **которые** теряют контракты из-за ручного мониторинга и не готовы платить 30+ т.р./мес за комбайны,
> **Тендер-радар** — это лёгкий self-hosted сервис, который сам присылает подборку релевантных закупок с дедлайнами на почту, в VK и MAX (а для демо — в Telegram),
> **в отличие от** Контур.Закупки/СБИС — дешевле, гибче по правилам и хранит данные внутри вашего контура.

## 5. Рамка успеха и метрики (рыночные)

**Портфолио-успех (первичная цель проекта):**
- Публичный репозиторий + развёрнутое демо + README со схемой архитектуры и GIF исполнения воркфлоу.
- Покрыты «галочки» вакансий: self-hosted N8N в Docker, queue mode+Redis, Error Workflow, sub-workflows, защита вебхуков, версионирование воркфлоу в git, опционально LLM.
- Кейс формулируется одной фразой: «экономит N часов ручного мониторинга в неделю, не пропускает дедлайны».

**Продуктовый успех (вторичная цель, гипотезы для проверки):**
- T1: ≥ 1 «пилотный» поставщик получает ежедневную подборку и подтверждает релевантность ≥ 70% присланного.
- T2: 0 пропущенных дедлайнов по настроенным правилам за период пилота.
- T3: время от «появилось в ЕИС» до «уведомление у пользователя» < 24 ч (при суточном расписании).

## 6. Рыночные ограничения

- **Регуляторика:** данные ЕИС общедоступны и бесплатны; коммерческая перепродажа сырых данных требует осторожности, но уведомления/обработка — допустимы.
- **Доступ к источнику:** токен ЕИС привязан к личности (Госуслуги). Для мультиарендной SaaS-модели в будущем нужно продумать модель токенов (свой токен на сервис vs токен клиента).
- **Лицензия N8N:** ограничивает чистую «N8N-as-a-service» перепродажу. Для портфолио/пилота — не блокирует.
- **Сегмент платит мало:** микробизнес чувствителен к цене → монетизация низким чеком, ставка на объём/white-label (Фаза 2+).

## 7. Монетизация (гипотеза, вне MVP-скоупа разработки)

- **MVP:** бесплатно / себе-в-портфолио, 1 пилотный пользователь.
- **Фаза 2+:** SaaS-подписка по числу «радаров» (наборов правил) и пользователей; премиум за LLM-скоринг и CRM-интеграцию; white-label для тендерных агентств.
